# تعمیرینو — مدیریت تعمیرات موبایل

نسخه اولیه قابل اجرا از یک برنامه فارسی و راست‌چین برای ثبت مشتری و تعمیر، ویرایش اطلاعات، تنظیم قالب رسید، جست‌وجوی برند و مدل، انتخاب مشکل، وضعیت تعمیر، گزارش، خروجی CSV و پشتیبان‌گیری JSON.

## اجرا
- فایل‌ها را روی یک وب‌سرور استاتیک مانند GitHub Pages قرار دهید.
- برای نصب PWA، سایت باید با HTTPS باز شود.
- داده‌ها در حافظه محلی همان مرورگر/دستگاه ذخیره می‌شوند؛ حذف داده‌های مرورگر ممکن است اطلاعات را پاک کند، پس مرتب پشتیبان بگیرید.

## تاریخ شمسی
فرم تاریخ، تاریخ جلالی با قالب `۱۴۰۵/۰۷/۲۳` می‌پذیرد و اعتبارسنجی تقویم انجام می‌دهد. تاریخ امروز نیز به شمسی نمایش داده می‌شود.

## امکانات این نسخه
- ثبت و ویرایش تعمیر و مشتری
- برندهای رایج + ورود برند دلخواه و مدل آزاد
- فهرست مشکلات رایج + توضیحات آزاد
- ویرایش تنظیمات چاپ رسید: نام تعمیرگاه، تلفن، آدرس، متن قوانین، نمایش IMEI و هزینه‌ها
- چاپ رسید یا ذخیره به PDF از پنجره چاپ دستگاه، اشتراک‌گذاری متن رسید
- وضعیت‌های پذیرش، در حال تعمیر، آماده تحویل و تحویل‌شده
- گزارش تعداد تعمیرها و جمع هزینه/بیعانه
- پشتیبان‌گیری و بازیابی JSON و خروجی CSV فارسی
- PWA و کش پایه برای استفاده آفلاین پس از بارگذاری اولیه
- اعلان‌های داخل برنامه و درخواست اجازه اعلان سیستمی؛ اعلان پایدار پس‌زمینه اندروید هنوز نیازمند پیاده‌سازی بومی است

## پیش از انتشار در کافه‌بازار
این نسخه را «نسخه اولیه قابل آزمایش» در نظر بگیرید، نه محصول نهایی تأییدشده. باید روی چند دستگاه اندرویدی تست شود؛ همچنین برای APK بومی، آیکون‌های استاندارد، نام بسته، امضای انتشار، مجوزها و اعلان پس‌زمینه را در یک پروژه Android/Capacitor تنظیم کنید. هیچ سرور یا همگام‌سازی ابری در این نسخه وجود ندارد.
